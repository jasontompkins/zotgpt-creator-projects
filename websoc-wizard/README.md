# WebSOC Wizard

WebSOC Wizard is an AI-powered tool that instantly transforms any UCI WebSOC Schedule of Classes PDF
into a clean, interactive web table. Simply upload your WebSOC PDF — from any department or school at 
UC Irvine — and WebSOC Wizard will automatically extract key course details such as course number, 
title, course code, instructor, meeting day and time, classroom, and enrollment, then present them in 
a searchable, sortable interface with a one-click Download CSV button for easy data export and analysis.
